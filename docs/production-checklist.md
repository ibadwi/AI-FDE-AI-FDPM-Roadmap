# قائمة جاهزية تطبيق AI للإطلاق

قائمة مراجعة أولية تُكيّف بحسب النظام والقطاع. اكتب الدليل أو سبب عدم الانطباق أمام كل بند؛ لا يكفي وضع علامة دون تحقق.

## المشكلة والقيمة

- [ ] يوجد مستخدم محدد ومالك للعمل وصاحب قرار إطلاق.
- [ ] وُثّق خط الأساس ومعيار النجاح وحدود النطاق.
- [ ] اختُبرت تجربة التصحيح والرفض والتصعيد.

## البيانات والصلاحيات

- [ ] مصادر البيانات واستخدامها مصرح بها ومحدّثة.
- [ ] تُطبق صلاحيات المستخدم عند الاسترجاع واستدعاء الأدوات.
- [ ] اختُبر عزل العملاء والحسابات والملفات.
- [ ] تُحمى الأسرار وتُحجب البيانات الحساسة من السجلات وفق السياسة.

## الجودة والتنفيذ

- [ ] توجد حالات تقييم ممثلة، وحالات صعبة، ومعايير قبول معلنة.
- [ ] تعالج المدخلات الناقصة والإجابة غير المدعومة وفشل الأدوات.
- [ ] اختُبر حقن التعليمات في المدخلات والمصادر المسترجعة.
- [ ] الإجراءات المؤثرة مقيدة بصلاحيات وتحقق مناسبين.
- [ ] تمنع إعادة المحاولة تكرار العمليات المؤثرة.

## التشغيل والاستمرار

- [ ] راقبت الجودة وزمن الاستجابة وتكلفة المهمة المقبولة تحت حمل مناسب.
- [ ] توجد حدود استخدام ومهل وتنبيهات ومسؤول استجابة.
- [ ] جُرّبت خطة التراجع والاستعادة في بيئة مناسبة.
- [ ] حُددت إصدارات المكونات ومعايير فحص أي تغيير.
- [ ] يعرف الفريق طريقة التشغيل والإيقاف ومسار التصعيد.
