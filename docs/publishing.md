# نشر الخارطة التفاعلية

الواجهة داخل `site/` ثابتة ولا تحتاج إلى حسابات أو مفاتيح API أو عملية بناء. بيانات المراحل موثقة في `site/roadmap.json`، ولكل مرحلة صفحة مستقلة داخل `site/levels/` مع قائمة جانبية وتنقل سابق وتالٍ. المحتوى معروض أيضًا داخل HTML ليبقى متاحًا دون JavaScript. عند تعديل المحتوى، حدّث المصدرين معًا أو أعد توليدهما.

## GitHub Pages

بعد رفع الملفات إلى `main`، افتح Settings ثم Pages، واختر GitHub Actions مصدرًا للنشر. يتضمن المستودع سير عمل يرفع مجلد `site` فقط ويشغّل النشر. تأكد من نجاح التشغيل قبل مشاركة رابط الموقع.

الرابط المتوقع بعد التفعيل: https://ibadwi.github.io/AI-FDE-AI-FDPM-Roadmap/

وجود الملفات أو سير العمل لا يعني أن النشر تم. راجع حالة Actions ثم افتح الرابط للتحقق.

## المعاينة محليًا

من جذر المستودع شغّل: `python3 -m http.server 8765 --directory site` ثم افتح `http://localhost:8765`.

تُحفظ علامات الإنجاز في تخزين المتصفح المحلي فقط. لا توجد تحليلات أو اتصالات API، وتعمل القراءة عند تعذر التخزين. لا يوجد تصدير أو مزامنة للتقدم بين الأجهزة. المظهر نهاري ثابت.

مصدر إعداد Pages: https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages

## العرض والخط

تعرض الصفحة الرئيسية خطًا زمنيًا للأساس المشترك ثم مسارين متفرعين. تستخدم IBM Plex Sans Arabic من Google Fonts عند توفر الاتصال، وخطًا عربيًا محليًا بديلًا عند تعذر تحميله. تبقى مراحل التعلم ونصوص الشرح متاحة دون الاعتماد على تحميل الخط الخارجي.
